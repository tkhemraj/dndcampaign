Everything at the Table

One toolkit, zero cloud dependencies. Runs on Python 3.11 + a modern browser.

🗺
Procedural Maps
BSP dungeon, outdoor terrain, five interior templates — 22 total subtypes including 10 Wildemount-specific presets. Renders on Canvas, exports PNG.
🎵
Live Browser Music
Eight moods synthesised with Tone.js — no audio files, no CDN media. Tavern, Dungeon, Combat, Boss Fight, Wilderness, Kryn, Calamity, Victory.
👹
Encounter Builder
CR-balanced monster groups against party level and size using XP budget thresholds. Easy/Medium/Hard/Deadly difficulty. Multi-creature multiplier applied.
⚔
Initiative Tracker
Roll initiative, track HP with colour-coded bars, apply conditions (Blinded, Frightened, Poisoned…), advance turns. Dead combatants greyed out.
🧙
NPC Generator
Wildemount name tables by culture (Zemnian, Xhorhasian, Coastal). Faction-aware backstories. All four Wildemount-unique races included.
📜
Quest Generator
Faction- and region-aware plot hooks across all 7 major factions. Reward tables scaled to party level. 17 curated Wildemount plot seeds.
📖
Lore Reference
Full Wildemount panel: all factions, regions, deities (including the Luxon), Dunamancy subclasses, and 17 plot seeds. Everything in one sidebar.
💾
Local SQLite Storage
Multiple independent campaigns, each in their own SQLite DB. No cloud account, no API key, no subscription. Your data stays on your machine.

Quick Start

Python 3.11+ and a modern browser. No API keys, no cloud accounts.

# Clone and run
git clone https://github.com/tkhemraj/dndcampaign.git
cd dndcampaign
pip install -r requirements.txt
python run.py

# Open in browser
http://localhost:8080

# Create a campaign → Generate maps → Roll initiative → Play music
